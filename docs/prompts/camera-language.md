# 镜头语言参考 (Camera Language)

## 焦段 (Focal Length)

| 焦段 | 效果 | 提示词用法 |
|------|------|-----------|
| 24mm | 广角, 透视夸张 | `shot on 24mm wide angle` |
| 35mm | 人文街拍, 自然 | `35mm documentary style` |
| 50mm | 标准镜头, 真实 | `50mm standard lens` |
| 85mm | 人像, 背景虚化 | `85mm portrait` |
| 135mm | 长焦, 压缩背景 | `135mm telephoto` |
| 200mm+ | 超长焦, 空间压缩 | `200mm telephoto compression` |

## 景别 (Shot Size)

| 景别 | 描述 | 提示词 |
|------|------|--------|
| Extreme Wide Shot | 大远景, 人物极小 | `extreme wide shot` |
| Wide Shot | 全景, 人物全身 | `wide shot, full body` |
| Medium Shot | 中景, 半身 | `medium shot, waist up` |
| Close-up | 特写, 脸部 | `close-up shot, face` |
| Extreme Close-up | 极特写, 局部 | `extreme close-up, eye detail` |
| Macro | 微距 | `macro photography` |

## 运镜 (Camera Movement)

| 运镜 | 效果 | 提示词 |
|------|------|--------|
| Static | 固定镜头 | `static shot` |
| Pan | 水平扫摄 | `panning shot` |
| Tilt | 俯仰 | `tilt up shot` |
| Dolly | 推拉 | `dolly in` / `dolly out` |
| Tracking | 跟拍 | `tracking shot` |
| Crane | 升降 | `crane shot` |
| Steadicam | 稳定器 | `steadicam shot, smooth` |
| Handheld | 手持 | `handheld camera, shaky` |

## 光圈 (Aperture)

| 光圈 | 效果 | 提示词 |
|------|------|--------|
| f/1.2 | 极浅景深 | `shot at f/1.2, extreme bokeh` |
| f/2.8 | 浅景深 | `f/2.8, creamy bokeh` |
| f/5.6 | 适中 | `f/5.6, sharp detail` |
| f/11 | 全景深 | `f/11, deep focus, everything sharp` |
