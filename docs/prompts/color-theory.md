# 配色参考 (Color Theory)

## 经典配色方案

| 方案 | 描述 | 提示词 |
|------|------|--------|
| Complementary | 互补色 | `complementary colors, blue and orange` |
| Analogous | 相邻色 | `analogous color scheme, green and blue` |
| Triadic | 三角色 | `triadic color scheme` |
| Monochromatic | 单色 | `monochromatic blue tones` |
| Tetradic | 四角色 | `tetradic color palette` |

## 情绪色调

| 色调 | 情绪 | 提示词 |
|------|------|--------|
| Warm | 温暖 | `warm amber tones, cozy` |
| Cool | 冷静 | `cool blue tones, clinical` |
| Teal-Orange | 青橙 (电影) | `teal and orange grade, cinematic` |
| Desaturated | 低饱和 | `desaturated, muted colors` |
| High Contrast | 高对比 | `high contrast, vivid colors` |
| Pastel | 粉彩 | `pastel colors, soft` |
| Cyberpunk | 赛博朋克 | `cyberpunk purple and cyan` |
