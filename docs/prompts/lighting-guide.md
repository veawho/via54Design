# 布光参考 (Lighting Guide)

## 经典布光

| 布光类型 | 效果 | 提示词 |
|----------|------|--------|
| Rembrandt | 伦勃朗光, 三角光 | `Rembrandt lighting` |
| Butterfly | 蝴蝶光, 好莱坞 | `butterfly lighting, Hollywood glamour` |
| Split | 分割光, 一半明一半暗 | `split lighting` |
| Loop | 环形光, 自然 | `loop lighting` |
| Rim | 轮廓光 | `rim lighting, backlight` |
| Silhouette | 剪影 | `silhouette lighting, backlit` |
