## 关键发现

### ✅ 摄影词典 100% 生效
v3 包含的 5 个摄影专业词在 C 图中**全部识别**:
- ✅ **Rembrandt Lighting (伦勃朗光)** — 猫脸三角形光斑
- ✅ **Volumetric god rays** — 窗光形成丁达尔效应
- ✅ **Kodak Portra 400** — 暖橙棕调,胶片颗粒
- ✅ **85mm f/1.4 portrait lens** — 焦外虚化质感
- ✅ **Shallow depth of field + bokeh** — 奶油背景虚化

### ❌ 主体细节失败 (mmx 训练偏差)
- ❌ **蓝眼 0% 复现**: mmx 给橘虎斑默认是绿眼 (3 张全绿/闭)
- ❌ **金属书架 0% 复现**: 私人图书馆语境下 mmx 必给木质
- 根因: mmx 训练集里"橘虎斑+蓝眼"是稀有组合,"图书馆+金属书架"违反主流摄影场景

### ⚠️ 越长 ≠ 越好
- A (中文 v1, 67 字符) → 8.4
- C (英文 v3 终极, 1024 字符, 7.6× 长) → 8.0
- **结论**: mmx LLM 注意力分散, 长度到 200-400 字符触顶

## 终极铁律 (★ 沉淀到 SKILL)

1. **mmx image-01 上限 8.0-8.4** (普通生图任务, 同类主体)
2. **mmx image-01-live 可能有 +0.5 提升** (有 style 字段) — 未测
3. **要蓝眼 → 换白猫/英短/布偶** (mmx 训练集优势)
4. **要金属书架 → 单图概念图 (非图书馆语境)** 
5. **要 9.0+ → 换 FLUX / MidJourney / GPT-Image-2** (mmx 不够)
6. **摄影词典 = 画质拉满 9.0**: Rembrandt + Kodak Portra + 85mm f/1.4
7. **prompt 200-400 字符 sweet spot** (中文 ≤ 100 字, 英文 ≤ 80 词)
8. **同 seed 字节级复现**: `--seed 42` 验证 v3 = C 图
