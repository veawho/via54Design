# 中文 AI 生图提示词精准调试指南

> 来源: 整合 `kkunkunya/image-prompt-layers` (7 层原理) + `waw666waw666/p2i-workflow` (A/B 窗口 + 中文优先) + `thinkingjimmy/Learning-Prompt` + 实战经验 (via54Design v0.5.3)

## 0. 为什么中文 prompt 经常"想得到说不出"

| 失败模式 | 原因 | 解决 |
|---|---|---|
| **"蓝宝石色眼睛" → 黄绿眼** | 模型把"反光呈蓝宝石色"理解为反光里有蓝色斑,不是眼本色 | 改写"**虹膜颜色是蓝宝石蓝**"或"**暹罗品种(默认蓝眼)**" |
| **"占画面 1/3" → 占 2/3** | mmx 没构图比例参数,描述比例是软建议 | 加"**wide shot establishing shot**"+ 远景术语 |
| **"绿色窗帘" → 没出现** | 模型自动简化背景,次要物件被压缩 | 显式说"**深绿色绒面窗帘(左侧,清晰可见,褶皱明显)**" |
| **中文字渲染成乱码** | 扩散模型对中文字形理解差,当装饰画出来 | 写"**no Chinese text**" 或用 logo 替代 |
| **风格"想到哪写到哪"** | 风格/主体/光线/构图混在一句 | 7 层结构 (Meta→Subject→Scene→Lighting→Camera→Details→Negative) |

## 1. 7 层结构骨架 (每层只回答 1 个问题)

```
[L0 Meta]    什么介质、什么风格、什么画幅、什么底色？
[L1 Subject] 谁/姿势/标志特征/表情？
[L2 Scene]   主体在哪、背景有什么、构图怎么分层、留白在哪？
[L3 Lighting] 光从哪来、色温多少、软硬、轮廓光？
[L4 Camera]  什么视角、什么焦段、什么光圈、什么虚化？
[L5 Details] 质感/材质/小钩子元素/文字处理？
[L6 Negative] 坚决不要什么？
```

### 写法的关键
- **L0 错了, 后面 6 层都白费** — 先花 3 秒决定"这条 prompt 走什么风格通道"
- **L1 写"具体是谁"** — 模型对精确角色执行力远强于模糊角色 (孙悟空 > 帅气的男人)
- **L2 显式留白** — 不写"留白", 模型会偷偷补满
- **L3 强光必写轮廓光** — 不写就出现"塑料人皮肤"
- **L4 焦段 ≠ 视角** — 50mm 是镜头焦距, 平视是视角, 别混
- **L5 文字明确处理** — "no text" / "English logo only" / "no Chinese text"

## 2. 中文 ↔ 英文 prompt 转换策略

### 2.1 何时用中文、何时用英文
- **中文**: 主体是中国文化元素 (汉服/水墨/古风/国风) / 用户中文母语
- **英文**: 西方元素 (西式建筑/欧美人像/西方油画) / mmx API 内部转换时
- **混合**: 主体英文 + 风格中文 (e.g. "a cat, 中国风水墨风格")

### 2.2 中文精准度提升技巧
1. **加"虹膜"前缀** — "蓝眼睛" → "**虹膜**蓝宝石蓝色"
2. **加品种** — "蓝眼睛" → "**暹罗猫**(默认蓝眼)"
3. **加材质前缀** — "金属书架" → "**拉丝金属**质感书架"
4. **加"清晰可见"后缀** — "绿色窗帘" → "**深绿色绒面窗帘(左侧,清晰可见,褶皱明显)**"
5. **加"wide shot"** — "主体 1/3" → "主体占画面 1/3,**wide shot establishing shot**"
6. **加"质感"前缀** — "毛发" → "**短毛**猫,**蓬松**毛发,**根根分明**"

### 2.3 容易踩雷的中文表达
| 写法 | 问题 | 改写 |
|---|---|---|
| "光从窗户来" | 没说方向 | "光从**左上方**窗户来" |
| "暖色调" | 太模糊 | "暖金琥珀色,**3000K 色温**" |
| "金属感" | 不知道什么金属 | "**拉丝金属**反光质感" |
| "细节丰富" | 模型没概念 | "**毛发根根分明+书脊花纹清晰+书页泛黄**" |
| "高级感" | 无画面元素 | "**胶片颗粒感轻微+8K 高清+电影感明暗对比**" |
| "很漂亮" | 主观评价 | 删除 |

## 3. A/B 双窗口工作流 (P2I)

```
A 窗口 (LLM):
  输入: 用户的粗略想法 ("做一张未来感女歌手海报, 霓虹灯, 酷一点")
  处理: 走 7 层结构展开
  输出: 单一主路线的"提示词2" (含中文最终 prompt + Negative + 可替换变量)
  禁止: 不能生图, 不能调生图工具, 不能说"我来生成图片"

B 窗口 (mmx image):
  输入: 提示词2 的"最终可复制提示词"代码块
  处理: 调 mmx image generate
  输出: 1 张或多张图
  禁止: 改 prompt 主体意思
```

### 单一主路线原则
- 1 个核心主体
- 1 个核心风格
- 1 个主要场景
- 1 个主要镜头
- 1 个主要材质方向
- 1 个主要画面目标

不要把"赛博朋克"和"水墨"混在一条 prompt 里。

## 4. 验证清单 (生成 1 张图后)

按顺序检查:
1. **L0 风格通道**对吗? 写实风出动漫 = 错
2. **L1 主体**对吗? 橘虎斑变黑猫 = 错
3. **L2 场景**对吗? 关键背景元素都有吗?
4. **L3 光线**对吗? 暖光/冷光/方向对吗?
5. **L4 镜头**对吗? 远景/特写/景深对吗?
6. **L5 细节**对吗? 关键质感都有吗?
7. **L6 Negative** 起作用了吗? 有没有 AI 味?

### 典型 1 偏离 → 修法对应表
| 偏离 | 修法 |
|---|---|
| 眼色不对 | 显式"虹膜+品种+眼色"三连 |
| 构图比例不对 | 加 wide shot/close-up/portrait |
| 背景元素缺失 | 显式"(位置, 清晰可见, 特征)" |
| 风格跑偏 | 重写 L0, 锁死介质+风格 |
| 文字乱码 | 加 "no text/no Chinese text" |
| AI 痕迹重 (多余手指等) | L6 加 deformed limbs, extra fingers |

## 6. 实战案例 (via54Design v0.5.3)

### 输入
```
一只橘色短毛猫(虎斑纹)趴卧在厚重的棕色皮面精装书的右半侧,
前爪自然交叠伸出书边,尾巴从书后绕过身体卷曲。
书脊有金色烫印花纹,书页边缘微泛黄并有岁月磨损痕迹。
主体位于画面中央偏左,占画面 1/3。
光线:左上方窗户透入温暖的金黄色黄昏光,主体边缘有金色轮廓光,
鼻梁与额头有自然高光,猫眼反光呈蓝宝石色。
...
```

### 失败 4 项
1. 蓝宝石眼 → 黄绿眼
2. 1/3 构图 → 2/3
3. 绿色窗帘 → 缺失
4. 金属书架 → 不明显

### v2 7 层改写
```
[L0 Meta] 摄影写实, 写实风格, 画幅 16:9, 暖色基调
[L1 Subject] 暹罗猫品种(默认蓝眼), 趴卧, 前爪伸出书边+尾巴从书后卷曲, 凝视镜头眼神警觉, 蓝眼睛(虹膜宝石蓝色)
[L2 Scene] 窗边木桌, 主体占画面 1/3 偏左 wide shot establishing shot, 右下角留白, 背景虚化的深绿色绒面窗帘(左侧,清晰可见,褶皱明显)+拉丝金属反光的现代书架(右侧,清晰可见)+绿色盆栽(右下角,叶片清晰)
[L3 Lighting] 窗户从左上方 3000K 暖金黄昏光, 柔和散射光, 强金色轮廓光
[L4 Camera] 平视微俯, 50mm 标准镜头, f/2.0 浅景深, 圆形奶油 bokeh
[L5 Details] 短毛猫毛发根根分明+皮面精装书+木纹桌, 棕色皮面+金色烫印+泛黄书页, 书脊花纹清晰, no Chinese text, no watermark
[L6 Negative] blurry, distorted, watermark, oversaturated, deformed limbs, extra fingers, ugly, low quality, cropped, plastic skin
```
