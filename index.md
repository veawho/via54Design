# via54Design

> **Design template engine + narrative engine + media pipeline.** 17 AI image platforms, 4 narrative models, HTMX Web UI, MCP Server. Pure Go single binary, zero runtime deps.

---

## What is it?

A Go CLI + MCP server for **declarative creative work**:

- **Template engine** — YAML-defined image / video / audio pipelines
- **Narrative engine** — 4 storytelling models (3-act, hero's journey, etc.)
- **17 image platforms** — ComfyUI, SD WebUI, mmx-cli, Gemini, etc.
- **MCP server** — integrate with Claude / Cursor / Hermes
- **HTMX web UI** — single-binary deployment
- **Zero runtime deps** — pure Go static binary

## Quick Start

```bash
go install github.com/veawho/via54Design/cmd/via54@latest
via54 --help
via54 comfyui --workflow portrait --prompt "..."
```
