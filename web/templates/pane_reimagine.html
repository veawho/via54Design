💡 用法说明

原理: 截图 → Base64 → LLM Vision API (GPT-4o / Claude / Gemini) → 纯 HTML+CSS 复刻

API Key: 在 OPENAI_API_KEY / ANTHROPIC_API_KEY / GEMINI_API_KEY 环境变量中设置

layout-hint / color-hint / font-hint: 可选, 强引导 LLM 走 via54Design 的对应 layout/color/font 风格

参考: 借鉴 abi/screenshot-to-code (73k⭐), 但保持 via54Design 单二进制零依赖路线

CLI 等价: via54 reimagine --screenshot shot.png --provider openai
