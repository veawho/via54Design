# Basic Hero Example

## Use Case
Single product / feature / announcement. Best for:
- Landing page hero section
- Press release cover
- Conference slide title
- Email campaign header

## Why This Combination

| Choice | Why |
|--------|-----|
| `hero-split-16-9` | Universal 16:9 ratio, works on all screens |
| `ink-wash` | Timeless Chinese aesthetic, low contrast for accessibility |
| `ming-hei-editorial` | Ming-style headlines + Hei-style body, professional |

## Customization

Try changing one parameter at a time:
```bash
# Modern tech feel
--color dark-terminal-blue --font hei-modern

# Luxury brand
--color tsubaki-camellia --font elegant-didone

# Education / kids
--color candy-duolingo --font playful-rounded
```

## Output
- File: `hero.html` (7-8 KB)
- Self-contained: 1 HTML file, no external CSS/JS
- Mobile-responsive: 4 breakpoints (mobile, tablet, laptop, desktop)
