# Bento Dashboard Example

## Use Case
4-quadrant data display. Best for:
- Product analytics dashboards
- Sales reports
- Social media summaries
- SaaS landing page "why us"

## Customizing Data

The 4 default values are placeholder (12,847 / $8.2M / 94.7% / 3,201).
To customize, edit `internal/export/export.go` or override via scaffold.
