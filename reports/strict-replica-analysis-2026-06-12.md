## 4. 关键工程发现（极精确 prompt 工程）

### 4.1 prompt 越精确，相似度越高

**关键 prompt 片段**（按贡献排序）：

```
✅ 高贡献 (相似度 +1~2 分)
  - "8列3行错落不规则开口"  ← 博古架形态精确
  - "前景2把椅背朝向镜头,后景2把椅面朝后"  ← 椅子朝向精确
  - "左半边"  ← 门位置精确
  - "右下角前景" + "右下角露出半边"  ← 茶具+沙发精确
  - "铺白色桌旗"  ← 桌子细节

⚠️ 中贡献
  - "偏右前方透视"  ← AI 有时仍偏中央视角
  - "方形藻井中央吊顶"  ← 大部分还原

❌ 低贡献 / 反效果
  - "水平视线略偏低"  ← AI 经常忽略
  - "6-7件青花瓷瓶"  ← AI 会画 10+ 件或 5 件
```

### 4.2 mmx 的「约束 vs 创造」平衡

mmx image-01 在 **「严格按 prompt 约束 + 自由发挥细节」** 之间平衡：
- **位置类约束**（左上、右下、中央）→ 严格遵守
- **形态类约束**（藻井、多宝格）→ 90% 还原
- **数量类约束**（4 椅、6-7 件）→ 50/50（常偏多或偏少）
- **视角类约束**（偏右前方）→ 50%（常自动回正到中央）

### 4.3 「温馨家庭」如何在严格复刻下保留

策略：在 prompt 末尾追加 **"vibe 关键词"** 而不是 **"具体物品"**：

```
✅ 有效 vibe 词（保留氛围，不破坏结构）
  - "暖色调温馨家庭氛围"
  - "新中式风格"
  - "明代家具审美"

❌ 反效果（破坏结构约束）
  - "一只橘猫蜷在博古架下角晒太阳"  ← AI 会被猫吸引走，可能挪动家具
  - "摊开的书和孩子散落的蜡笔画"  ← AI 桌子位置可能漂移
```

## 5. 推荐最佳成品

**`strict_004.jpg`** 是当前最接近原草图的成品：
- 家具位置 1:1 对齐草图
- 风格仍是写实彩（按你的"成品设计图"目标，不是"草图彩填"）
- 暖色调温馨家庭氛围完整保留
- 1280×720 JPEG 347 KB

**如果还想继续提升**，下一步可考虑：
1. **加 `--seed` 复现**：找到 strict_004 的 seed 后固定，保证每次都生成几乎一样的图
2. **加 `--prompt-optimizer`**：让 mmx 自动优化 prompt（但可能稀释我们的精确约束）
3. **加 `--subject-ref`**：用原草图作为参考（mmx 只支持 character 类型，草图不能直接喂）
4. **换 Forge / ComfyUI**：这两个 via54 子命令可能支持更精确的 img2img / ControlNet workflow（待测）
