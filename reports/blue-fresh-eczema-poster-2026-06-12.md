## 5. 关键工程发现

### 5.1 中文文字 AI 限制 ⚠️

**mmx image-01 模型对中文文字处理能力严重不足**：
- 所有 4 张图的中文都成了乱码 / 错字 / 类似日文伪字
- 这是 **mmx/AI 模型的已知限制**，不是 prompt 问题
- 同样的英文 prompt 在 MJ/Flux 上中文也会有类似问题

**解决方案**（生产海报时）：
1. **AI 出图后用 PIL 二次加工**：用 PIL 的 ImageDraw 把正确的中文文字贴到 AI 生成的图上
2. **用 SVG 矢量文字代替位图**：海报类设计天然适合 SVG 文字（via54 有 export svg 命令）
3. **改用 via54 generate 命令**：先生成 HTML（HTML 文字是真字体），再 export png/svg

### 5.2 「蓝底清爽风」转换效果

| 原图风格 | 蓝底清爽版 |
|---------|-----------|
| 灰底（暗色） | 浅蓝渐变（亮色） |
| 黑白线稿 | 黑白线稿 + 蓝色色块 |
| 水珠装饰 | 水珠装饰保留 |
| 黑色文字 | 黑色文字保留（位置） |
| 严肃医疗感 | 清爽治愈感 |

**4 张图都成功实现了"灰→蓝"的色调转换**，整体氛围从"严肃医疗"变为"清爽治愈"。

### 5.3 人物对比还原

- ✅ 4 张全部是"左焦虑 + 右微笑"的对比布局
- ⚠️ AI 经常把左侧女性画得"过度焦虑"（看起来像惊恐），原图是"眉头紧锁的烦恼"，不是惊恐
- 左侧女性 AI 经常中性化（短发 + 简笔 = 像男生），原图明显是女性
- **解决方案**：加更多女性化细节 prompt（"delicate feminine features", "soft jawline"）

## 6. 实战建议（设计师可复用）

### 6.1 海报类设计的两步走策略（推荐）

```bash
# 第一步: AI 出图（无文字版本）
via54 img --scene "<场景 + 人物 + 构图>" --platform minimax --ar 16:9 --n 4

# 第二步: 用 PIL/Photoshop 后期加工文字
python add_chinese_text.py  # 在 AI 图基础上加正确的中文 + 按钮文字
```

### 6.2 一键脚本（自动后期）

```python
from PIL import Image, ImageDraw, ImageFont
# 把 AI 生成的图 + 中文文字合成
def add_chinese_text(base_path, text_list, output_path):
    img = Image.open(base_path).convert('RGB')
    draw = ImageDraw.Draw(img)
    # 用思源黑体或类似中文字体
    font = ImageFont.truetype("/System/Library/Fonts/PingFang.ttc", 100)
    # 绘制中央文字
    for i, text in enumerate(text_list):
        y = 100 + i * 120
        draw.text((img.width//2, y), text, font=font, fill='black')
    img.save(output_path)
```

### 6.3 via54 内部能力

```bash
# via54 generate 命令可以生成 HTML（文字是真字体）
via54 generate --layout hero-split-16-9 --color cosmic-retro --font hei-modern

# 然后 export png / svg
via54 export png
via54 export svg  # SVG 文字是矢量的
```
