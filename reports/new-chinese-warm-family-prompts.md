**生成日期**: 2026-06-12
**目标**: 把一张设计草图（线稿）扩展为成品设计图（温馨家庭氛围）
**工具链**: via54Design v0.7.1 + mmx 1.0.16 + image-01 模型
**来源草图**: `composer_2026-06-12_08-20-51-649_7993de.png`（中式线稿：八仙桌 + 官帽椅 + 博古架 + 双开门）

## 1. 草图 → 成品 的设计思路（人写一句 → AI 结构化扩展）

草图提供**空间骨架**：家具位置、家具类型、门窗方位、天花地面。  
「温馨家庭」prompt 提供**生活气息 + 时间氛围 + 情感色温**。

| 草图元素 | prompt 升级 |
|---------|------------|
| 红木八仙桌 + 4 把官帽椅 | 中央红木八仙桌配四把官帽椅 (明代家具审美) |
| 博古架 + 几件花瓶 | 博古架陈列青花瓷和祖传紫砂壶 |
| 双开门 | 左侧双开门 (格栅门, 通庭院) |
| 右下角茶具 | 右前景茶几上紫砂壶 + 茶杯冒着热气 + 一缕茶烟 |
| 空白墙面 | 墙上挂中式水墨 / 全家福相框 |
| 空地面 | 木质地板温暖 + 午后金色阳光斜入 |
| 无植物 | 吊兰从博古架下垂 + 窗边文竹 + 大盆绿植 |
| 无线索"家庭" | 沙发亚麻靠垫 + 针织毯 + 父亲摊开的书 + 孩子蜡笔画 + 橘猫晒太阳 |

设计决策：**保留草图所有元素 + 加 5-7 个家庭生活细节**，AI 自然会把它们织成"有人住的家"。

## 2. 推荐的两个 Prompt 模板

### 2.1 Prompt v1（不出现人物）— 适合做静态样板间

```
新中式客厅兼茶室,中央红木八仙桌配四把官帽椅,右墙博古架陈列青花瓷和紫砂壶,左侧双开门,
右前景茶几上紫砂壶和茶杯冒着热气,沙发上米色亚麻靠垫和针织毯,木质地板温暖,
午后金色阳光从窗外斜入,墙上挂中式山水小品,茶桌摊开的书和孩子蜡笔画,吊兰从博古架下垂,
整体氛围温馨家庭生活气息,新中式风格,明代家具审美,暖色调,室内设计效果图,建筑可视化
```

**特点**: 不强调人物 → 适合样板间 / 房地产 / 软装方案展示。

### 2.2 Prompt v2（具象化"家人"）— 适合做情感化营销

```
新中式家庭客厅茶室,主人视角,中央红木八仙桌刚泡过茶,桌上有父亲摊开的古籍和孩子散落的蜡笔画,
沙发上有母亲盖着的针织毯和绣花靠垫,一只橘猫蜷在博古架下角晒太阳,博古架陈列青花瓷和祖传紫砂壶,
窗边绿植吊兰和文竹,午后金色阳光从格栅窗洒入,木质地板温暖,墙上挂全家福相框和中式水墨,
一缕茶烟袅袅升起,生活气息浓厚,新中式风格,室内设计渲染图
```

**特点**: 给出具体角色（父亲/母亲/孩子/猫）和动作 → AI 会自己加人物剪影 + 物品细节，**情感温度最高**。

## 3. 多平台对照（via54 prompt 引擎 + minimax 真生图）

| 平台 | prompt 引擎输出 | 真生图效果 | 推荐度 |
|------|----------------|------------|--------|
| **minimax** | 直通中文原文（保留全部细节） | ✅ image-01 实测效果最佳 | ⭐⭐⭐⭐⭐ |
| **midjourney** | 26 维度转"摄影写实 + 暖色调 + cinematic"，**丢失中式室内细节** | ⚠️ 仅通用摄影 prompt，中式元素不显 | ⭐⭐ |
| **flux** | 同 MJ，丢失中式细节 | ⚠️ 同上 | ⭐⭐ |
| **kling** | 26 维度 + 视频参数（dura/fps/motion），**目标是视频不是图** | ⚠️ 不适合本任务（室内静帧） | ⭐ |

### 关键发现 ⚠️

via54 prompt 引擎对**通用摄影风格**优化过头，遇到中式室内/手绘/具体风格等垂类时，会**把原文简化成通用摄影模板**，丢失关键设计意图。

**实战策略**：
- minimax 平台 → 直接用 `--platform minimax --dry-run` 看 prompt，**它的中文直通最完整**
- MJ/Flux 平台 → **手工改 prompt**，加 `(New Chinese interior:1.3) (Ming dynasty furniture:1.2)` 等加权词组，不要信任自动展开

## 5. 命令可复用模板

### 5.1 设计师速用（真生图）
```bash
export VIA54_BASE_DIR=/Users/david/Desktop/developments/via54Design

# 单张 (16:9 默认)
via54 img --scene "<你的中文描述>" --platform minimax --ar 16:9 --n 1

# 多张同 prompt 看多样性
via54 img --scene "<你的中文描述>" --platform minimax --ar 16:9 --n 4

# 竖图 (9:16 适合手机/小红书)
via54 img --scene "<你的中文描述>" --platform minimax --ar 9:16 --n 2
```

### 5.2 仅看 prompt 不真生图（设计稿阶段）
```bash
# minimax 中文直通版（最完整）
via54 prompt --scene "<中文描述>" --platform minimax

# 26 维度全展开版（看引擎覆盖度）
via54 prompt --scene "<中文描述>" --platform midjourney  # 或 flux/kling/dalle3/sd3/...
```

### 5.3 固定种子复现最佳版
```bash
# 找到最佳图后, 用 --seed 复现
via54 img --scene "<同 prompt>" --platform minimax --seed 12345 --n 1
```

## 6. 中文 prompt 编写技巧（实战总结）

**有效**：✅
- 家具 + 位置 + 材质："红木八仙桌"、"格栅门"、"青花瓷"、"紫砂壶"
- 时间 + 光线："午后金色阳光"、"格栅窗光斑"
- 家人角色 + 动作："父亲摊开的书"、"母亲针织毯"、"孩子蜡笔画"、"橘猫蜷睡"
- 风格 + 媒介词："新中式风格"、"明代家具审美"、"室内设计渲染图"
- 否定用正面描述："整体氛围温馨家庭生活气息"（比"不要冷冰冰"有效）

**无效**：❌
- 纯形容词堆砌："很温馨很美好的家"（模型不知道具体画什么）
- 抽象情感："充满爱的空间"（同上）
- 西方摄影词主导（minimax 中文场景不要硬塞 "shallow DOF"）
